# Rohanle

Open `index.html` in a modern browser. The dictionary and game are embedded; no installation or server is required.

Reach ERIC, ROHAN, or MEILIN by changing exactly one letter per move. Word length is locked to the target: four for ERIC, five for ROHAN, and six for MEILIN. Rohanle, Ericle, and Meilinle each have a separate tab and daily puzzle. Starting words are selected deterministically each day at midnight UTC, so everyone gets the same three puzzles. Each start has a route of at least five moves to its target.

Green tiles match the target in position. Hints, undo, shortest-route scoring, and copied results follow the selected target. Progress and hints are saved locally for each tab and day. Existing v4 progress is retained in the matching name’s tab. Use the arrow keys, Home, or End to switch tabs from the keyboard.

The dictionary includes four-to-six-letter entries from the public-domain Webster’s Second International word list supplied with macOS, plus the special destination names.
