# Rohanle

Open `index.html` in a modern browser. The dictionary and game are embedded; no installation or server is required.

Reach ERIC, ROHAN, or MEILIN by adding, removing, or changing exactly one letter per move, using words of four to six letters. The target and starting word are selected deterministically each day at midnight UTC, so everyone gets the same puzzle. Each start has a route of at least five moves to its target.

Green tiles match the target in position. Hints, undo, shortest-route scoring, and copied results follow the selected target. Progress is saved locally. The v3 puzzle selection resets progress from the previous version, including today’s game.

The dictionary includes four-to-six-letter entries from the public-domain Webster’s Second International word list supplied with macOS, plus the special destination names.
